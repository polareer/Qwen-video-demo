# 项目目标

这个项目的目标不应该只停留在“看懂一张截图”，而是要能够理解一个第一人称增强现实装配视频，并输出对业务真正有用的结果，例如：

- 当前正在执行哪个装配步骤
- 操作者拿了什么零件、用了什么工具
- AR 画面给了什么提示，提示是否和实际动作一致
- 哪一步容易出错、哪里有风险
- 如何改进装配流程、培训内容和 AR 引导

## 当前项目现状

目前仓库只完成了图片理解的最小样例：

- `download_qwen.py`：下载 `Qwen2.5-VL-3B-Instruct`
- `run_qwen_image.py`：对单张图片做视觉问答

这离“视频理解”还差几个关键能力：

- 缺少视频输入与抽帧理解
- 缺少步骤级时序分析
- 缺少针对装配任务的结构化输出
- 缺少对 AR 指引、手部动作、零件状态变化的专门建模

## 已完成的第一步改进

仓库现在新增了 `run_qwen_video.py`，可以直接把视频送入 Qwen2.5-VL，输出适合装配场景的结构化分析结果。

同时新增了一个前端输入页 `frontend/index.html`，可以用于：

- 上传视频并本地预览
- 配置模型参数
- 编辑分析 Prompt
- 生成标准 JSON 请求体
- 生成对应的命令行

前端页面可以直接双击打开，也可以在项目目录运行：

```bash
python -m http.server 8080
```

然后访问：

```text
http://127.0.0.1:8080/frontend/
```

示例：

```bash

```

## 针对“第一人称 AR 装配视频”的建议改进方向

### 1. 先把输出目标定义清楚

不要一开始就追求“模型完全看懂视频”，而是先把输出定义成几个稳定字段：

- `assembly_goal`：本次装配任务是什么
- `steps`：拆出的装配步骤列表
- `objects`：每一步涉及的零件、工具、工装
- `ar_guidance`：AR 叠加层提示了什么
- `possible_issue`：这一步的风险或疑点
- `improvement_suggestions`：系统改进建议

这样后面无论换模型、加检测器、加 OCR/ASR，接口都不容易变。

### 2. 从“整段视频理解”升级到“分阶段理解”

第一人称装配视频最大的难点不是看不见，而是时间连续性太强：

- 头动会带来剧烈视角变化
- 手会遮挡零件
- AR 标注和真实物体可能短暂错位
- 真正重要的信息往往出现在动作切换瞬间

建议把流程改成：

1. 视频粗采样，获得全局摘要
2. 自动切分关键片段，例如“拿取零件”“对位”“固定”“检查”
3. 对每个片段单独分析
4. 最后汇总成完整步骤链

### 3. 加入多信号，而不是只靠纯视觉大模型

如果后面要做得稳定，建议逐步加入这些模块：

- OCR：识别 AR 文字、编号、步骤提示
- ASR：如果视频里有语音讲解，可以拿到更强的步骤线索
- Hand-Object 理解：判断手正在操作哪个零件或工具
- 目标检测/分割：持续跟踪关键零件状态变化
- 时间轴事件检测：识别“开始装配”“完成固定”“返工调整”等事件

也就是说，Qwen 更适合做“高层语义理解”，而不是单独承担全部感知任务。

### 4. 面向业务，把“理解”变成“可评估”

如果这个项目最终要用于培训、质检或辅助装配，建议把结果落成可评分项：

- 步骤识别准确率
- 漏步检测率
- 错步检测率
- 风险动作召回率
- AR 提示和实际动作一致率
- 单视频分析耗时

没有这些指标，项目容易停留在“看起来挺聪明”，但很难真正交付。

## 建议的技术路线

### 阶段一：先做可演示版本

- 用 `run_qwen_video.py` 直接跑整段视频
- 输出摘要、步骤拆分、风险点、优化建议
- 人工检查结果是否可用

目标：先验证模型是否能大致看懂这类视频。

### 阶段二：做步骤级时序系统

- 增加抽帧和片段切分
- 对每个片段单独调用多模态模型
- 输出统一 JSON
- 保存每一步的时间范围

目标：让结果从“整段描述”升级到“可追溯步骤链”。

### 阶段三：做面向生产的增强

- 接 OCR / ASR / 检测器
- 加入装配知识库和标准 SOP
- 自动比对“标准步骤”与“实际步骤”
- 生成错误预警和培训反馈

目标：让系统具备真正的业务价值。

## 下一步最值得做的事

如果继续推进，我建议优先做下面三件事：

1. 先用新增的视频脚本跑你那段 HoloLens 视频，看看模型能不能拆出合理步骤
2. 如果能拆出来，再把输出固定成标准 JSON schema
3. 再进一步做“视频切片 + 每片单独分析”，提升稳定性

## 一个务实判断

“理解第一人称增强现实装配视频”这个目标是可做的，但不要把它理解成一次性解决“完整视频理解”。

更现实的做法是：

- 先做到“能给出靠谱摘要和步骤拆分”
- 再做到“能识别关键动作和风险点”
- 最后再做到“和标准装配流程比对，并给出改进建议”

这样项目推进会更稳，也更容易做出可展示、可验收的版本。
